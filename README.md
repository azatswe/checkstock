# CheckStock

Небольшой MVP веб-прототип складского учёта. Требуемый стек тестового задания: Python, FastAPI, PostgreSQL. Основа проекта и схема PostgreSQL добавляются небольшими отдельными этапами; складские функции пока не реализованы.

## Запуск локально

Требуется Python 3.9 или новее.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
uvicorn app.main:app --reload
```

Откройте <http://127.0.0.1:8000/>. Проверка доступности приложения: <http://127.0.0.1:8000/health>.

## Запуск PostgreSQL и создание схемы

Требуется Docker Compose. Локальные настройки берутся из `.env`:

```bash
cp .env.example .env
docker compose up -d db
set -a && source .env && set +a
python -m app.db
```

Команда `python -m app.db` создаёт минимальную схему PostgreSQL. Её можно запускать повторно. Таблицы хранят товары, ФФ, баланс товара на ФФ и журнал операций. Остатки отделены от истории; ограничения базы не позволяют сохранить отрицательный остаток или резерв больше физического количества. Тестовые товары и складские операции будут добавлены отдельными следующими задачами.

Чтобы остановить PostgreSQL, не удаляя локальные данные, выполните `docker compose down`. Не используйте `docker compose down -v`, если хотите сохранить локальную базу.
